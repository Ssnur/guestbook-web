# Қонақ кітабы

Қазақ тіліндегі статикалық қонақ кітабы. Жазба қосуға, есім бойынша іздеуге, жазбаны өшіруге және барлық жазбаларды көруге болады. Жазбалар осы браузердің `localStorage` қоймасында сақталады, сондықтан басқа құрылғылармен синхрондалмайды.

## Жергілікті іске қосу

`index.html` файлын браузерде ашыңыз. Қосымша бағдарлама, сервер, Azure тіркелгісі немесе виртуалды машина қажет емес.

## GitHub Pages арқылы жариялау

1. Жобаны GitHub репозиторийіне `main` немесе `master` тармағына жүктеңіз.
2. Репозиторийде **Settings → Pages → Build and deployment → Source** бөлімінен **GitHub Actions** таңдаңыз.
3. `main` немесе `master` тармағына әр push жасалғанда workflow сайт файлдарын тексеріп, GitHub Pages-ке жариялайды. Оны **Actions** бөлімінен бақылауға болады немесе workflow-ды қолмен іске қосуға болады.

Workflow Azure құпиясөздерін немесе жариялау профилін қажет етпейді. Жарияланған сайттағы жазбалар да әр келушінің өз браузерінде ғана сақталады.
